This page needs to be served over HTTP

The dashboard reads its numbers from ./data/*.json at runtime. Browsers block those reads (and ES module loading) when a page is opened directly from disk as file://, so no panel can populate in this mode.

From the docs/ directory, run a local server and reload from the address it prints:

python3 -m http.server 8000

Then open http://localhost:8000/. Published to GitHub Pages, the site is served over HTTPS and works without any of this.
